# Cplusplus-Bank

# Overview

This is a mock banking software that utilizes 2 different menus, one for the customer allowing to view their account
and deposit and withdraw, it also allows the customer to delete their account. The Manager menu allows for the use of adding an account
the name of the account, and the starting balance of the account. The manager is also is able to view all the accounts and delete 
whichever account they want to. The program utilizes a list to give an ID to each account and store the accounts using iterators. 

I wanted to write a program that has some real world application, I also think that working with menus is good because pretty much every software
uses menus. Lists I think are heavily utilized in many programs and wanted to be able to learn how to use them in C++.
